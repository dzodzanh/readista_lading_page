# Readista — landing page

Static site for the Readista iPhone app, deployed with GitHub Pages
(`.github/workflows/static.yml`, Pages source: **GitHub Actions**).

- `index.html` — landing page
- `privacy.html` — Privacy Policy (linked from the app and App Store Connect)
- `terms.html` — Terms of Use / EULA
- `support.html` — Support URL for App Store Connect
- `images/` — screenshots from the iOS simulator, widget renders, app icon

Live: https://dzodzanh.github.io/readista_lading_page/
